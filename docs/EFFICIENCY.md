# Efficiency counting and timing

Archived same-protocol code used RGB1x3x256x256 on RTX4090, FP32, no AMP/compile, eval/no_grad, TF32 disabled, cudnn deterministic true and benchmark false. Three repetitions each use100 warmup and500 timed forwards, CUDA synchronize before perf_counter and after each forward. GPU input is preloaded. Timing includes teacher/student/AE, saved train/validation discrepancy normalization, actual fusion, pad4, resize256 and image-max score. I/O, CPU preprocessing, H2D, calibration computation, native resize and metric calculations are excluded. Do not compare older kernel-only/partial-boundary FPS directly.

Parameters count all unique registered parameters, teacher included. 1MAC=2FLOPs; actual Conv2d(including depthwise/pointwise), Linear and fixed functional convolution are counted. Pooling, interpolation, activation, BatchNorm arithmetic, normalization, elementwise ops and shuffle are not comprehensively counted but execute during runtime. HIC has0learnable parameters and two fixed3x3convolutions on56x56maps. No benchmark was executed for this release candidate; the archived machine-specific orchestration is not advertised as a portable verified benchmark command.
